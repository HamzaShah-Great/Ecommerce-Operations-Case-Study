# E-commerce Operations Case Study — Rivia Hair Oil (Shopify)

A real operational audit and financial systems build 
for a private-label health & beauty brand on Shopify.

## What This Covers
- Financial data pipeline built in Python
- SKU-level margin analysis
- Automated monthly P&L reconciliation
- Shopify operations management

## Result
Reduced monthly financial close from 8-10 hours to 
under 30 minutes through automation.
