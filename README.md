# E-Commerce Operations Case Study

A real operational audit and financial systems build for a 
private-label health & beauty brand on Shopify.

## The Problem
Data fragmentation across Shopify, payment gateways, and ad spend 
meant true net margin per SKU was completely invisible. 
Financial close took 8–10 hours monthly, done manually.

## What Was Built
- Python-based financial data pipeline (pandas, openpyxl)
- SKU-level margin tracking framework
- Automated monthly P&L reconciliation
- SKR03-aligned bookkeeping structure for DACH market readiness

## Result
85% reduction in financial reporting time.
Full per-SKU margin visibility achieved for the first time.
Monthly close reduced from 8–10 hours to under 30 minutes.
